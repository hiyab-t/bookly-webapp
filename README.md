# Bookly

## Overview
Bookly is a simple Go-based web application with focus on the backend design and minimal frontend to interact with API.

## Tech Stack
- Go
- PostgreSQL
- Docker
- Bash

## Features
- RESTful API for managing books (CRUD operations)
- structured JSON responses
- request validation
- environment-based configuration
- consistent error handling across handlers
- pagination and filtering
- PostgreSQL integration with migrations
- Docker-based setup
- single-command run script
- minimal HTML + inline JS frontend for interacting with the API

## Prerequisites

- Go (to run the API)
- Docker (to run the PostgreSQL database)

# How to run

```bash
    cd backend
    ./run.sh
```

Reload the page when it comes up on the browser.
